# paginaweb2 — brutalismo arquitectónico

Landing en un único `index.html` (HTML + CSS + JS vanilla, Three.js r128 desde cdnjs).

Interpretación del brutalismo desde la arquitectura, no desde el "web brutalism":
hormigón visto con berenjenos, encofrado de tablas, enlucido de cal, arcos y
hornacinas, luz natural rasante y una paleta cálida de piedra, arena, carbón y
un único acento coñac (el terciopelo del mobiliario de referencia).

- Todas las texturas se generan por código (canvas); no hay imágenes externas.
- Hero: pieza en Three.js sobre un pedestal de hormigón dentro de un arco, con
  sombra suave y construcción capa a capa.
- Taller: generador paramétrico delante de un muro de tablas con aro de luz.
- Colección: piezas en hornacinas; al pasar el cursor, su sección constructiva.
- Clases con prefijo `pw-` por componente.
